# Cat-term

A simple script to display a cat in the terminal

# What’s inside

1. ASCII art of a cat
2. Color (bold light gray)

# Installation

1. Run the following command in your terminal: `git clone https://github.com/kirieshka228-govno/asciicat-term.git`
2. Go into the cat-term folder with: `cd asciicat-term`
3. Run the script with: `./cat-term.sh`
4. Done! Now you have a cat in your terminal (you can exit the program by pressing Ctrl + C)
